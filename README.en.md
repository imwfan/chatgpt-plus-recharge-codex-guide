“ChatGPT recharge” or “GPT top-up” commonly refers to activating or renewing a ChatGPT subscription. Before ordering, distinguish between these products:

| Your goal | What to check |
| --- | --- |

| Call models from your application | Separate API billing rules; a subscription purchase is not an API balance top-up |
